# PM GOLD · Запись к Елене

Интерактивный блок записи для сайта школы-студии перманентного макияжа Елены Ткаченко. Стоит в конце главной страницы.

- **Работающая страница:** https://aeriiiaaa.github.io/pm-gold/
- **Прототип в Figma:** https://www.figma.com/design/JpMGtwQiAz6BMHlGdKhq11/Untitled?node-id=2-1692

## Какую задачу решает

Core Job проекта: *когда я хочу выглядеть ухоженно каждый день, не тратя время на макияж, я хочу заранее убедиться, что результат перманента будет естественным, а процедура безопасной, чтобы решиться на неё без страха.*

Из исследования и интервью видно, что мастера выбирают по работам, отзывам и рекомендациям. Клиентку останавливает страх неестественного результата.

Обычная форма «имя + телефон» ничего не объясняет. Поэтому запись идёт по шагам: человек сам выбирает направление, процедуру и зону, сразу видит технику и цену «от», а перед отправкой — итог своего выбора. Так понятно, на что именно он записывается и что будет дальше.

Расположение: в конце главной, после портфолио, блока о мастере и частых вопросов, когда доверие уже сформировано. Кнопки «Хочу на услугу» и «Хочу на обучение» из блока «Направления студии» ведут сюда.

## Как работает

4 шага.

1. **Выберите, с чего начнём:** процедура или обучение.
2. **Процедура:** перманент, коррекция, удаление, ламинирование.
   **Обучение:** курс с нуля или повышение квалификации.
3. **Зона.** Набор зон зависит от шага 2 (у удаления — брови, губы, глаза; у ламинирования — ресницы и брови). В каждой плитке техника и цена «от».
4. **Контакты:** сверху строка «Вы выбрали: Перманент · Губы · от 10 500 ₽», имя, телефон с маской, способ связи (Telegram, WhatsApp, звонок), согласие.

После отправки: «Заявка отправлена» и что будет дальше (для процедуры — договориться о бесплатной консультации, для обучения — рассказать о программе и датах).

Состояния: неактивная кнопка «Далее», пока ничего не выбрано; ошибки полей при отправке; «Отправляем…»; финальный экран.

## Устройство кода

```
src/javascripts/
├── index.js                  — монтирует компонент в <div id="booking">
└── booking/
    ├── data.js               — все тексты, цены и зоны (меняются в одном месте)
    ├── plan.js               — логика: шаги, варианты для каждого шага, строка «Вы выбрали», телефон
    └── BookingQuiz.jsx       — компонент с состоянием и шагами
src/stylesheets/booking.css   — стили, повторяют прототип: фон #0F0F0F, Inter, обводка без скруглений
```

- Все ответы хранятся в одном объекте `answers` (`useState`).
- Выбор на раннем шаге сбрасывает ответы после него, чтобы зона от одной процедуры не осталась у другой.
- `getZones(answers)` возвращает зоны в зависимости от выбранной процедуры или курса.
- Бэкенда в учебном проекте нет, отправка имитируется задержкой. На реальном сайте здесь будет запрос в CRM или Telegram-бот студии.

## Запуск

```
npm install
npm start       # локальный сервер для разработки
npm run build   # сборка в папку docs
```

Публикация: папка `docs` раздаётся через GitHub Pages (Settings → Pages).
